# EAVESENCE Energy

EAVESENCE Energy ist ein kostenloser, zweisprachiger Stromkosten-Rechner für typische Haushaltsgeräte. Die Anwendung zeigt Kosten pro Nutzung, Woche, Monat und Jahr und funktioniert ohne Anmeldung oder eigenes Tracking.

## Website

- Produktion: [eavesence.com](https://eavesence.com)
- Deutsch: [eavesence.com](https://eavesence.com)
- English: [eavesence.com/en](https://eavesence.com/en)

## Funktionen

- Stromkosten-Rechner mit typischen oder eigenen Verbrauchswerten
- Gerätebibliothek mit deutsch- und englischsprachigen Detailseiten
- Berechnung für leistungs- und verbrauchsbasierte Geräte
- Responsive Oberfläche für Desktop und Mobilgeräte
- SEO-Metadaten, Sitemap und Robots-Konfiguration
- Kein Benutzerkonto und kein eigenes Analytics-Tracking

## Lokale Entwicklung

Voraussetzungen: Node.js und npm.

```bash
npm install
npm run dev
```

Danach ist die Anwendung unter [localhost:3000](http://localhost:3000) erreichbar.

## Qualitätsprüfung

```bash
npm run lint
npm run build
```
