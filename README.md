# EAVESENCE Energy

EAVESENCE Energy ist ein kostenloser, zweisprachiger Stromkosten-Rechner für typische Haushaltsgeräte. Die Anwendung zeigt Kosten pro Nutzung, Woche, Monat und Jahr und funktioniert ohne Anmeldung.

## Website

- Produktion: [eavesence.com](https://eavesence.com)
- Deutsch: [eavesence.com](https://eavesence.com)
- English: [eavesence.com/en](https://eavesence.com/en)

## Funktionen

- Stromkosten-Rechner mit frei bearbeitbaren Startwerten und optionalem Messwert
- Gerätebibliothek mit deutsch- und englischsprachigen Detailseiten
- Berechnung für leistungs- und verbrauchsbasierte Geräte
- Nutzungsszenarien und direkter Gerätevergleich
- Lokale Geräteliste mit Import und Export – ohne Benutzerkonto
- EAVESENCE-Home-Dashboard mit Räumen, Sparziel und monatlichem Verlauf
- Pro-Preisvorschau und messbare Beta-Interessenabfrage
- Mehrere europäische Währungen
- Responsive Oberfläche für Desktop und Mobilgeräte
- SEO-Metadaten, Sitemap und Robots-Konfiguration
- Anonymisierte, cookielose Nutzungsanalyse ohne Übertragung eingegebener Berechnungswerte
- Installierbares Web-App-Manifest für Mobilgeräte und Desktop
- Gemeinsamer Berechnungskern für Web, iOS und Android
- Expo-App-Grundlage mit lokaler Speicherung, Erinnerungen und vorbereiteten In-App-Abonnements

## Lokale Entwicklung

Voraussetzungen: Node.js und npm.

```bash
npm install
npm run dev
```

Danach ist die Anwendung unter [localhost:3000](http://localhost:3000) erreichbar.

## Qualitätsprüfung

```bash
npm run lint
npm run build
npm run typecheck:mobile
```

## Status

EAVESENCE Energy ist derzeit ein privates, nicht kommerzielles Projekt. Die
Consumer-App befindet sich in der vorbereiteten Beta-Phase; Store-Veröffentlichung
und echte Abonnements werden erst nach Produktvalidierung und Einrichtung der
zugehörigen Entwicklerkonten aktiviert.
