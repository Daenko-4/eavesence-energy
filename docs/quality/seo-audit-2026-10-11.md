# EAVESENCE technical search audit — 11 October 2026

The live site was checked before this patch. All 76 URLs advertised by
`https://eavesence.com/sitemap.xml` returned HTTP 200, with a matching canonical
URL and no `noindex` meta directive. The main landing, My Home and calculator
pages in English and German also had no `X-Robots-Tag` restriction.
`robots.txt` allows crawling and points to the reachable sitemap. Public pages
retain their URLs; this patch does not require a URL migration.

These observations establish technical eligibility, not actual Google indexing
or ranking. Search Console opened its public sign-in page in the available
browser; no authenticated indexing, sitemap or URL-inspection report was read.

## Changes in this patch

- Apple touch icons and manifest icons were still pointing at the previous
  leaf logo. They now use the unchanged nine-cell mark from `BrandLogo.tsx`.
- Dedicated 180px Apple, 96px search and 192/512px manifest images include
  breathing room. Conventional `/apple-touch-icon.png` and `/favicon.ico`
  endpoints are supplied as well. Organization structured data uses the same
  current mark. The new asset URLs remain stable after this update.
- The service worker cache version changes, so its old branding assets no
  longer remain the active cached shell. Household storage is unaffected.
- Sitemap `lastmod` values no longer claim every page changed on every build.
  No artificial modification dates are emitted until content dates are tracked.

## After deployment

1. Inspect the domain homepage and the main My Home/calculator URLs in Search
   Console. Compare declared and Google-selected canonicals and inspect the
   latest crawl. Review the Pages report for exclusion reasons.
2. Confirm the sitemap is successful and still contains the expected URLs.
   Request a new crawl of the homepage once for the favicon update if needed;
   a mass re-index request is not necessary merely because the header changed.
3. Re-create the affected Safari favorite after loading the deployed page to
   refresh its icon. Do not clear household website storage as part of icon
   maintenance.

Google can take days or weeks to process a changed favicon and does not
promise its display. This delay is distinct from a page-indexing error.
